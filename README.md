# Health Food

Концепт сайта доставки здорового питания в Алматы. Структура и фирменная основа — [health-food.kz](https://health-food.kz/).

- [Посмотреть сайт](https://dusky-brumm.github.io/health-food/)

- [Поддержание веса](https://dusky-brumm.github.io/health-food/programs/balance/)
- [Набор массы](https://dusky-brumm.github.io/health-food/programs/mass-gain/)

## Запуск

Node.js 22 или новее.

```sh
npm ci
npm run build
npm run dev
```

Предпросмотр: `http://127.0.0.1:4173/`. После сборки с префиксом Pages сервер перенаправит на `/health-food/`.

Сборка генерирует четыре HTML-страницы, собирает React-карусель через esbuild, проверяет внутренние ссылки, фрагменты, файлы и синтаксис JavaScript. `npm run check` отдельно проверяет синтаксис клиентского кода.

`npm test` проверяет жизненный цикл анимаций: уменьшенное движение, отмену эффектов, однократное появление секций, статичные отзывы, видимость при фокусе и отказ API анимации.

## Публикация

Исходники находятся в `main`, статический сайт — в `gh-pages`. В Settings → Pages выбран источник **Deploy from a branch → gh-pages → / (root)**.

```sh
git add .
git commit -m "Update Health Food"
git push origin main
npm run deploy
```

`deploy.mjs` определяет префикс по репозиторию в `origin`, собирает сайт и отправляет `dist/` в `gh-pages` через временный изолированный Git-репозиторий. Основной checkout не переключается. Используется существующая Git-аутентификация; секреты в проекте не хранятся. Завершение команды означает отправку ветки; готовность публикации показывает Pages build в GitHub Actions.

## Исходники

- `src/site-data.mjs` — программы, команда и видеоотзывы.
- `src/render-pages.mjs` — страницы, общие хедер и футер.
- `src/templates/` — общие диалоги и пример недельного меню.
- `src/app.js` — калькулятор, квиз, меню, видео и черновик заявки.
- `src/site-motion.js` — однократное появление заголовков и цветных пятен, мягкая смена цен и меню; карточки и блок отзывов статичны.
- `src/site.css` — адаптивная вёрстка, чередующиеся фоны и мягкие волны, связанные с прокруткой.
- `src/vendor/dish-orbit/` — выбранная карусель, лицензия и происхождение.
- `dist/styles.css` — сохранённые базовые стили меню, форм и диалогов.
- `dist/assets/` — локальные шрифты и изображения.
- HTML-страницы, `dist/app.js`, `dist/site.css` и `dist/assets/dish-orbit/` генерируются сборкой.

## Содержание

Хедер → первый экран → спецпредложение и подбор → программы и цены с примерами блюд → пробный день → отзывы → о сервисе → команда → повторный пробный день → кухня → статьи → текст о доставке → контакты → футер.

Каждая программа имеет подробную страницу: назначение, стоимость на 1/5/20 дней, пример меню, доставка и ответы на вопросы. Выбранное число дней передаётся из карточки на подробную страницу.

## Материалы

Логотип, фото в `dist/assets/original/`, команда, видеоотзывы, контакты и начальные цены — из публичной версии [health-food.kz](https://health-food.kz/) от 27 ноября 2026 года. Палитра: зелёный `#8cc832`, жёлтый `#fff55a`, тёмный хедер. Права на бренд и материалы остаются у правообладателей. Это демонстрационный редизайн, не официальный сайт компании; установлен `noindex, nofollow`.

Карусель — опубликованное демо [Food Menu Scroll Carousel](https://21st.dev/@kedhareswer/components/dish-orbit-carousel), **Kedhareswer Naidu**, MIT. Лицензия, ресурсы и адаптации сохранены в `src/vendor/dish-orbit/`. Повара, оценки и блюда внутри неё — данные демо, не отзывы или сотрудники Health Food.

Прайсинг реализован самостоятельно на основе выбранного [Prism UI Pricing от Codehagen](https://preview.21st.dev/@Codehagen/components/pricing): три карточки, выделенная центральная и переключатель периода. Фото и данные примерного меню сохранены из предыдущей версии концепта и не являются подтверждённым меню кухни.

Визуальная доработка опирается на методику [Unslop](https://github.com/heydamir/unslop) Дамира Соколовского, CC BY 4.0.

В основе всех блоков — визуальный стиль карусели. Локальный Outfit используется для латиницы и цифр, Manrope — для кириллицы. Шрифты и лицензии SIL OFL находятся в `dist/assets/`.

## Демонстрационные формы

Сайт не принимает заказы и платежи. Форма готовит скачиваемый TXT-черновик и не отправляет персональные данные на сервер. Они остаются в текущей вкладке. Для реального запуска нужно подтвердить меню, цены, акции, калорийность и доставку, подключить обработку заявок и юридические документы.

Видео YouTube загружается после нажатия. В диалоге есть прямая ссылка при недоступности встраивания.
