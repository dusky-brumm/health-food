# Health Food

Концепт нового сайта сервиса готовых рационов в Алматы. Основная страница — HTML/CSS/JavaScript; оригинальная карусель блюд с 21st.dev подключена отдельным React-компонентом с GSAP. Шрифты, фотографии и изображения блюд размещены локально.

## Запуск

Требуется Node.js 22 или новее.

Для установки зависимостей и изменения React-карусели:

```sh
npm ci
npm run build
```

```sh
npm run dev
```

Предпросмотр: http://127.0.0.1:4173

```sh
npm run build
```

Команда собирает карусель через esbuild и проверяет JavaScript, используемые файлы и конфигурацию публикации. Готовый сайт находится в `dist/`.

## Возможности

- Три программы и периоды 1, 5 и 20 дней с пересчётом итоговой стоимости.
- Меню на пять дней, состав, аллергены и пример пищевой ценности блюд.
- Оригинальная Food Menu Scroll Carousel: орбитальная смена пяти блюд, цветная дуга, вкладки описания и состава, миниатюры, клавиатура и свайпы. Карусель загружается при приближении к разделу меню.
- Подбор программы по предпочтениям с сохранением ответов при переходе назад.
- Форма черновика заказа с проверкой телефона, адреса и даты; скачивание TXT и копирование.
- Мобильная навигация, управление с клавиатуры, нативные модальные окна, режим reduced motion.

## Демонстрационные данные

Сайт не принимает реальные заказы и платежи. Форма ничего не отправляет и не сохраняет введённые данные между перезагрузками. Для запуска бизнеса нужно подключить обработку заявок, согласовать меню, цены, доставку и юридические документы. Примерные суточные цены взяты с исходного сайта и требуют подтверждения.
