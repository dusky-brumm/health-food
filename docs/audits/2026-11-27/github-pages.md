# Проверка версии для GitHub Pages

27 ноября 2026 года. Локальный сервер запущен с тем же префиксом `/health-food/`, что и публикация. Проверка в браузере Codex, desktop 1440×950 и мобильные ширины 390/320 px.

## Выполнено

- Сборка четырёх страниц, JavaScript syntax check, проверка всех статических внутренних ссылок, файлов и фрагментов — успешно.
- Главная, переходы на все три программы и прямое открытие подробных страниц работают с префиксом репозитория.
- Цены на 20 дней: 165 000 / 222 000 / 232 000 ₸. Длительность передаётся из карточки через `?days=5`: на странице «Баланс» сумма 55 500 ₸.
- В заявке выбирается программа нажатой карточки; на подробных страницах предвыбрана соответствующая программа. Для набора массы на 5 дней — 58 000 ₸.
- Телефон из трёх цифр показывает ошибку; исправление и отправка демонстрационной формы создают текстовый черновик с выбранными программой, периодом и стоимостью. Сеть для отправки данных не используется по коду обработчика.
- Квиз после трёх ответов переходит на соответствующую подробную страницу с выбранным периодом.
- Вкладки дней, окно состава блюда, мобильное меню и ссылки возврата на главную работают.
- Окно заказа входит в modal-состояние, фон исключается из accessibility tree; Escape закрывает окно и возвращает фокус на кнопку открытия.
- Нажатие видеоотзыва добавляет iframe с правильным ID и ссылку YouTube; закрытие удаляет iframe. Само воспроизведение внешнего видео отдельно не проверялось.
- Включённая карусель загружается; исходные изображения доступны по префиксу Pages. В desktop режиме сохраняется конечная прокрутка; на мобильном — статический компактный режим.
- Исправлен выход вкладок меню за границу экрана. После исправления на 320 px `scrollWidth` равен `clientWidth` (305 px без полосы прокрутки); на desktop горизонтального переполнения также нет.
- Повреждённых загруженных изображений и ошибок консоли в проверенном сценарии не обнаружено.
- `git diff --check` и поиск распространённых шаблонов секретов в исходниках и документации — без замечаний.

## Ограничения

Reduced motion проверен по коду CSS и React-медиаусловиям; принудительная эмуляция этого предпочтения в текущем браузерном инструменте недоступна. Заявки, платежи и фактическое меню кухни не подключены: это демонстрационная версия. Полная матрица браузеров и устройств не проверялась.
